# 🌿 ЭкоТаълим — экологик таълим платформаси

Аҳоли, корхоналар ва таълим муассасалари учун бепул, замонавий экологик таълим платформаси.

## Имкониятлар

- **Интерактив курслар** (5 курс, 29 дарс): аҳоли учун «Экология асослари», корхоналар учун «Корхонада экологик менежмент» (ISO 14001, энергия самарадорлиги, ESG), ўқувчи ва талабалар учун «Барқарор ривожланиш ва яшил технологиялар».
- **Дарсликлар асосидаги курслар** (17 дарс): ТКТИ олимларининг «Экологик мониторинг» (2024) дарслиги ва «Саноат оқова сувларини биокимёвий тозалаш» (2025) ўқув қўлланмаси мазмуни қисқа дарслар ва тестлар шаклида, манба кўрсатилган ҳолда.
- **Тестлар ва сертификат** — ҳар бир дарсдан кейин тест, курс якунида исм ёзилган PNG сертификат.
- **Энг сўнгги янгиликлар** — тоифалар бўйича филтр ва қидирув, 7 кунлик янгиликларга «ЯНГИ» белгиси.
- **Ҳаво сифати — жонли**: Ўзбекистоннинг 13 шаҳри бўйича AQI, PM2.5, PM10, NO₂ (Open-Meteo / Copernicus CAMS очиқ маълумотлари, калит талаб қилинмайди).
- **Углерод изи калькулятори** — шахсий йиллик CO₂ ва шахсий тавсиялар.
- **Геймификация** — XP, даражалар (Уруғ → Табиат ҳимоячиси), нишонлар, кунлик эко-челленж ва серия (streak).
- **Эко-ёрдамчи** — экология бўйича саволларга жавоб берувчи чат.
- **3D ЭкоГолограмма** (`hologram.html`) — 7 та 3D саҳна (Ер, сув айланиши, дарахт, Орол, иқлим, қайта ишлаш, яшил энергия): Pepper's ghost пирамидаси учун 4 томонлама кўриниш, проектор учун битта кўриниш, LED-вентилятор учун квадрат «🌀 Вентилятор» режими, кўзгу акси, тегиниш билан бошқариш, видео ёзиш ва пирамида шаблонлари. Қурилмалар рўйхати: [HOLOGRAMMA-QURILMALAR.md](HOLOGRAMMA-QURILMALAR.md). Вентиляторни ясаш, такомиллаштириш ва тайёр видеолар: [LED-VENTILYATOR.md](LED-VENTILYATOR.md).
- **PWA** — телефонга илова сифатида ўрнатиш ва офлайн ишлаш; тун/кун режими; мобил мослашувчан дизайн.

## Ишга тушириш

Сервер ёки йиғиш (build) талаб қилинмайди:

```bash
python3 -m http.server 8000
# браузерда: http://localhost:8000
```

**GitHub Pages орқали эълон қилиш:** Settings → Pages → Branch: `main`, папка: `/ (root)`.

## Контентни янгилаш

Барча контент `js/data.js` файлида:

- `NEWS` — янгиликлар (янгисини рўйхат бошига қўшинг, сана `ЙЙЙЙ-ОО-КК`);
- `COURSES` — курслар, дарслар ва тест саволлари;
- `DAILY_TIPS`, `CHALLENGES`, `ASSISTANT_KB` — маслаҳатлар, челленжлар ва ёрдамчи жавоблари.

Контентни ўзгартиргач, `sw.js` даги `CACHE` номини (масалан `ekotalim-v2`) ошириб қўйинг.

Фойдаланувчи натижалари (XP, дарслар) браузернинг ўзида сақланади.

## Тузилма

```
index.html      — асосий саҳифа
css/style.css   — дизайн (ёруғ/қоронғи мавзу)
js/data.js      — контент
js/app.js       — мантиқ
hologram.html   — 3D экологик голограмма
css/hologram.css, js/hologram.js — голограмма дизайни ва мантиқи
js/holo-geo.js  — қуруқлик чегаралари (Natural Earth, public domain)
js/vendor/three.min.js — three.js r149 (MIT), офлайн ишлаши учун репозиторийда
sw.js, manifest.json, icon.svg — PWA
```
