# 🌿 ЭкоТаълим — экологик таълим платформаси

Аҳоли, корхоналар ва таълим муассасалари учун бепул, замонавий экологик таълим платформаси.

## Имкониятлар

- **Интерактив курслар** (3 йўналиш, 12 дарс): аҳоли учун «Экология асослари», корхоналар учун «Корхонада экологик менежмент» (ISO 14001, энергия самарадорлиги, ESG), ўқувчи ва талабалар учун «Барқарор ривожланиш ва яшил технологиялар».
- **Тестлар ва сертификат** — ҳар бир дарсдан кейин тест, курс якунида исм ёзилган PNG сертификат.
- **🏛️ Экология вазирлигидан сўнгги маълумотлар** — «Янгиликлар» бўлимидаги панел. Вазирликнинг расмий манбаларидан (eco.gov.uz, хоҳишга кўра Telegram канали) ҳар 3 соатда автоматик йиғилади; ҳар бир хабар асл манбага ҳавола қилади.
- **Энг сўнгги янгиликлар** — тоифалар бўйича филтр ва қидирув, 7 кунлик янгиликларга «ЯНГИ» белгиси.
- **Ҳаво сифати — жонли**: Ўзбекистоннинг 13 шаҳри бўйича AQI, PM2.5, PM10, NO₂ (Open-Meteo / Copernicus CAMS очиқ маълумотлари, калит талаб қилинмайди).
- **Углерод изи калькулятори** — шахсий йиллик CO₂ ва шахсий тавсиялар.
- **Геймификация** — XP, даражалар (Уруғ → Табиат ҳимоячиси), нишонлар, кунлик эко-челленж ва серия (streak).
- **Эко-ёрдамчи** — экология бўйича саволларга жавоб берувчи чат.
- **Эко-кутубхона** — 11 та йўқолиб бораётган ҳайвон (IUCN мақоми, «Биласизми?» фактлари, хавфлар ва уларни асраш йўллари), экологияга оид 8 та машҳур китоб ва 12 та қонун ҳамда халқаро конвенциянинг оммабоп мазмуни. Ҳар куни янги «Кун ҳайвони», қидирув, филтрлар, ўқилган материаллар учун XP ва нишонлар.
- **Кирилл ва лотин алифбоси** — тепадаги «Lotin / Кирилл» тугмаси бутун саҳифани расмий ўзбек лотин алифбосига ўгиради (сертификат ҳам). Танлов эсда қолади; ҳаволага `?lang=lat` қўшиб, сайтни тўғридан-тўғри лотинда очиш мумкин.
- **PWA** — телефонга илова сифатида ўрнатиш ва офлайн ишлаш; тун/кун режими; мобил мослашувчан дизайн.

## Ишга тушириш

Сервер ёки йиғиш (build) талаб қилинмайди:

```bash
python3 -m http.server 8000
# браузерда: http://localhost:8000
```

**Битта HTML файл** (серверсиз, икки марта босиб очиш учун):

```bash
python3 tools/build_single_html.py   # → dist/EkoTalim.html
```

**GitHub Pages орқали эълон қилиш:** Settings → Pages → Branch: `main`, папка: `/ (root)`.

## Вазирлик маълумотлари панели

Браузер вазирлик сайтига тўғридан-тўғри мурожаат қилмайди (CORS ва ишончлилик сабабли). Ўрнига:

1. `.github/workflows/ministry.yml` ҳар 3 соатда `tools/fetch_ministry.py` ни ишга туширади.
2. Скрипт `data/ministry_sources.json` даги манбаларни ўқийди: аввал сайтнинг RSS/Atom лентасини излайди, топилмаса янгиликлар саҳифасидаги ҳаволаларни олади; Telegram учун `t.me/s/<канал>` очиқ саҳифасини ўқийди.
3. Натижа `data/ministry.json` га ёзилади ва (ўзгарган бўлса) `main` га коммит қилинади. Панел шу файлни кўрсатади.

**Ишга тушириш:** ўзгаришлар `main` га қўшилгач, GitHub'да **Actions → «Вазирлик маълумотларини янгилаш» → Run workflow** ни босинг. Кейин у ўзи ҳар 3 соатда ишлайди. Агар Actions репозиторийга ёзолмаса: Settings → Actions → General → Workflow permissions → «Read and write permissions».

**Telegram каналини қўшиш:** `data/ministry_sources.json` да `telegram` манбасига вазирликнинг расмий канал номини ёзинг (`"channel": "..."`, @ белгисиз) ва `"enabled": true` қилинг. Канал ҳақиқатан вазирликники эканига ишонч ҳосил қилинг.

**Қўлда қўшиш:** автоматик йиғиш ишламай қолса, хабарларни `data/ministry_manual.json` га қўшинг.

Хавфсизлик: фақат `allowed_hosts` рўйхатидаги доменлардан `https://` ҳаволалар қабул қилинади, матндан HTML теглар тозаланади, саҳифада эса барча матн экранланган ҳолда кўрсатилади.

Тестлар: `python3 -m unittest discover -s tools`

## Контентни янгилаш

Барча контент `js/data.js` файлида:

- `NEWS` — янгиликлар (янгисини рўйхат бошига қўшинг, сана `ЙЙЙЙ-ОО-КК`);
- `COURSES` — курслар, дарслар ва тест саволлари;
- `DAILY_TIPS`, `CHALLENGES`, `ASSISTANT_KB` — маслаҳатлар, челленжлар ва ёрдамчи жавоблари.

Кутубхона контенти `js/library.js` файлида: `LIBRARY.animals`, `LIBRARY.books`, `LIBRARY.laws`. Қонунлар мазмуни оммабоп қисқача баён; расмий матн — [lex.uz](https://lex.uz).

Контент фақат кириллда ёзилади — лотин версияси автоматик ҳосил бўлади (`js/translit.js`).

Контентни ўзгартиргач, `sw.js` даги `CACHE` номидаги рақамни ошириб қўйинг (масалан `ekotalim-v2` → `ekotalim-v3`).

Фойдаланувчи натижалари (XP, дарслар) браузернинг ўзида сақланади.

```
data/ministry*.json        — вазирлик панели маълумотлари ва созламалари
.github/workflows/ministry.yml — ҳар 3 соатлик автоматик янгилаш
```
